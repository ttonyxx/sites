sleep-when-done

Close the lid.
Claude keeps working.

Normally, closing your MacBook puts it to sleep, even mid-task. With sleep-when-done, the Mac stays awake until your Claude Code sessions finish, then goes to sleep. Take it with you and lose Wi-Fi, and it switches to your iPhone's hotspot so the work keeps going. 

$ sleep-when-done status
Lid closed, staying awake for 14m so far. working: Fix flaky tests, Landing page
  Offline for 12s, trying the hotspot.

Set it up

Ask your agent easiest

Paste this into Claude Code. It installs the tool, checks that it works, and finds your phone's hotspot. You'll type your Mac password once.

Set up sleep-when-done on my Mac by following https://tonyxin.com/sites/sleep-when-done/agent.md

Or run it yourself

Downloads one bash script and installs it as a small background service.

cd "$(mktemp -d)" && curl -fsSLO https://tonyxin.com/sites/sleep-when-done/sleep-when-done && sudo bash sleep-when-done install

Needs macOS 15 or later and Claude Code. Read the script before running it.

When you close the lid

  1. Claude keeps working

    If any session is busy, the Mac stays awake with the screen off. Nothing new starts after the lid is closed. It only finishes what was already running.

  2. Wi-Fi gone? Hotspot.

    If the internet drops for 10 seconds, it joins your phone's hotspot. It picks your own phone automatically, the one named after you, like "Alex's iPhone".

  3. Done, then sleep

    When the last session finishes, it waits 90 seconds in case Claude starts another turn, then puts the Mac to sleep.

Commands

sleep-when-done statusWhat it's doing, and every live session
sleep-when-done disableTurn it off. Closing the lid sleeps the Mac right away again.
sleep-when-done disable 2hTurn it off for a while
sleep-when-done enableTurn it back on
sleep-when-done hotspotShow the hotspot it uses. Add auto, off or "Name" to change it.
sleep-when-done logWhat it did, and why
sudo sleep-when-done uninstallRemove everything

Safety

  • Gives up and sleeps after 3 hours with the lid closed, at 10% battery, or if the Mac runs hot (say, in a bag).
  • Questions don't count. A session waiting for your answer won't keep the Mac awake, since nobody is there to answer it.
  • External display? In clamshell mode it never sleeps the Mac for you.
  • Fails safe. If the service ever stops, normal lid sleep comes back. As a manual reset, sudo pmset -a disablesleep 0 always works.
  • For the hotspot, the Mac must have joined it once before. On the iPhone, turn on Personal Hotspot → Allow Others to Join. On the Mac, set Wi-Fi → Ask to join hotspots → Automatic for the smoothest switch.
